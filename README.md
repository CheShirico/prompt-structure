# Анализ промптов: как контекст меняет ответ

Сравнение двух версий одного запроса к ИИ — «акции и мероприятия для пивного бара»:
первая версия без контекста, вторая с конкретными вводными. Цель — показать, что именно в структуре промпта влияет на качество ответа.

---

## 1. Промпты

### Промпт «до»

> Напиши 3 варианта акции и мероприятии для пивного бара

### Промпт «после»

> Напиши 3 варианта возможных акции и мероприятии для пивного бара в г. Алматы, при условии что бар работает с четверга по воскресенье с 15.00 до 00.00, для привлечения новых гостей в четверг и воскресенье, с расчетом на аудиторию от 25 до 35 лет, без выделения большого бюджета на проведение этих мероприятии

---

## 2. Структура промптов

| Элемент промпта | «До» | «После» |
|---|---|---|
| **Задача** (что сделать) | ✅ 3 варианта акций и мероприятий | ✅ то же |
| **Объект** | ✅ пивной бар (без деталей) | ✅ пивной бар |
| **Локация** | ❌ не указана | ✅ г. Алматы |
| **График работы** | ❌ не указан | ✅ чт–вс, 15:00–00:00 |
| **Цель** | ❌ не указана | ✅ привлечь новых гостей в чт и вс |
| **Целевая аудитория** | ❌ не указана | ✅ 25–35 лет |
| **Ограничения (бюджет)** | ❌ не указаны | ✅ без большого бюджета |
| **Количество вариантов** | ✅ 3 | ✅ 3 |

**Итог:** в первом промпте задана только задача и количество. Во втором добавлены пять недостающих элементов: локация, график, цель, аудитория, ограничение по бюджету.

---

## 3. Что изменилось в ответах

### 3.1. Краткое содержание ответов

**Ответ «до»** — универсальные идеи для любого бара:
1. «Пивной паспорт» — программа лояльности со штампами за новые сорта.
2. «Тап-тейковер» — вечер одной пивоварни раз в две недели по четвергам.
3. «Пивной квиз + Happy Hour» — по вторникам.

**Ответ «после»** — идеи под конкретные условия:
1. «Квиз-четверг» с ранним Happy Hour (17:00–19:00, для тех, кто идёт с работы).
2. «Sunday Chill» — настолки, спортивные трансляции, фиксированный воскресный сет.
3. «Колесо удачи» + «Приведи друга» — механика на оба дня с контентом от гостей.

### 3.2. Сравнение по параметрам

| Параметр | Ответ «до» | Ответ «после» |
|---|---|---|
| **Привязка ко дням** | Вторник и «четверг раз в 2 недели», то есть дни, когда бар может быть закрыт | Только четверг и воскресенье, с распределением по дням |
| **Цель акций** | Удержание гостей (лояльность), имидж, загрузка будней | Привлечение **новых** гостей |
| **Время суток** | Не учитывалось | Happy Hour 17–19 под выход с работы, квиз в 20:00, воскресенье — спокойный формат |
| **Локальный контекст** | Нет | Тенге (₸), 2GIS, чаты коворкингов и бизнес-центров Алматы, Telegram |
| **Аудитория 25–35** | Нет привязки | После работы, компании, настолки, футбол/UFC/F1, UGC в сторис |
| **Бюджет** | «Низкий/средний», встречается идея со средним бюджетом (закупка партии, приезд пивовара) | Только низкий, очень низкий и минимальный; идея со средним бюджетом убрана |
| **Конкретика расходов** | Только слова «низкий/средний» | Оценки в ₸ (игры, колесо, розыгрыш) — это оценки, не проверенные данные |
| **Юридический аспект** | Нет | Предупреждение об ограничениях рекламы алкоголя в Казахстане |
| **Измерение результата** | Нет | Рекомендация сравнить через 4–6 недель: число гостей, средний чек, новые гости |
| **Итоговая рекомендация** | Таблица «цель → вариант» | Таблица «день → бюджет → эффект» и план запуска: №1 по четвергам, №2 по воскресеньям, №3 поверх |
| **Следующий шаг** | Предложение уточнить формат бара | Предложение подготовить анонсы, контент-план, вопросы для квиза |

### 3.3. Что сохранилось

- Формат: три пронумерованных варианта с блоками «суть», «зачем», «бюджет».
- Идея квиза пережила переработку: из вторника её перенесли на четверг.
- Обе версии заканчиваются сводной таблицей и предложением продолжить.

### 3.4. Что исчезло и почему

| Убрано | Причина |
|---|---|
| «Пивной паспорт» (лояльность) | Цель сменилась: нужны новые гости, а не удержание существующих |
| «Тап-тейковер» | Требует среднего бюджета (партия, пивовар) |
| Вторник | Бар по вторникам не работает |

---

## 4. Выводы

1. **Чем больше вводных, тем меньше «воды».** Универсальный ответ подходит всем и потому почти никому. Вторая версия сразу применима к конкретному бару.
2. **Цель важнее темы.** «Привлечь новых» и «удержать своих» дают принципиально разные механики. Без цели ИИ выбирает случайно.
3. **Ограничения сужают поиск.** Бюджет и график отсекли часть идей и заставили придумать дешёвые механики вроде UGC и «приведи друга».
4. **Локация подтягивает локальные детали**: валюту, площадки продвижения, правовые нюансы.
5. **Аудитория определяет тон и формат**: после работы, компании, соцсети.

---

## 5. Шаблон хорошего промпта

```
Задача:       Напиши [N] вариантов [чего именно]
Объект:       для [тип бизнеса / продукта]
Локация:      в [город / регион]
Условия:      [график, сезон, площадка]
Цель:         для [привлечения / удержания / роста чека]
Аудитория:    [возраст, интересы, поведение]
Ограничения:  [бюджет, сроки, ресурсы, запреты]
Формат ответа: [таблица / список / с примерами цен]
```

Опционально: добавить критерий успеха («как поймём, что сработало») и попросить сравнение вариантов в таблице.

---

## 6. Ограничения этого анализа

- Сравнивались ответы одной модели на два промпта, по одному ответу на каждый. При повторном запуске ответы будут отличаться.
- Цифры в ₸ в ответе «после» — ориентировочные оценки, а не проверенные цены рынка Алматы.
- Замечание об ограничениях рекламы алкоголя в Казахстане носит общий характер и требует проверки у юриста.
